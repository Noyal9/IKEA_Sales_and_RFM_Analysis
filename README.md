# IKEA Sales & RFM Analysis

## Project Overview
An interactive Power BI dashboard developed to analyze sales performance, customer behaviour, customer segmentation, and churn patterns using Python and Power BI.

## Tools Used
- Python (Pandas, Jupyter Notebook)
- Microsoft Excel
- Power BI
- DAX

## Project Workflow
- Data preparation and cleaning using Python and Excel.
- RFM analysis (Recency, Frequency, Monetary).
- Customer scoring and segmentation into six categories.
- Churn identification based on 90 days of inactivity.
- Interactive dashboard development using Power BI.

## Dashboard Pages

**1. Business Overview**
- Total Customers
- Total Revenue
- Churn Percentage
- Average Customer Value
- Revenue by Segment and Time Period

**2. RFM Analysis**
- Customer Segmentation
- RFM Scores
- Average Customer Value by Segment
- Monthly, Quarterly and Yearly Churn Analysis

## Key Insights
- Identifies high-value and at-risk customers.
- Highlights customer purchasing behaviour.
- Analyzes revenue trends and customer churn.

Original and processed datasets are excluded due to their large file sizes.
